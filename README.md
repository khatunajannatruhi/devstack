# DevStack App

A modern React application for developers to build their ultimate software development stack. It provides a beautiful interface to browse and select various technologies.

## Key Features
- **Modern UI:** Built using Tailwind CSS with beautiful gradients and clean components.
- **Dynamic Stack Management:** Add, remove, and clear selected technologies with real-time state updates.
- **Notifications:** Integrated with React Toastify for instant user feedback.
- **Responsive Design:** Optimized for mobile, tablet, and desktop devices.

## Technologies Used
- React (Hooks, State)
- Vite
- Tailwind CSS
- React Toastify

## Getting Started

First, install the project dependencies:
```bash
npm install
```

Then, run the local server:
```bash
npm run dev
```

Navigate to `http://localhost:5173` to explore the app.
